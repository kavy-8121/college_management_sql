# College Management System | MySQL

## Project Overview

The **College Management System** is a relational database project developed using MySQL to manage student information, course details, and student enrollments.

This project demonstrates practical SQL skills in database design, data manipulation, relational queries, and data analysis. It covers essential SQL concepts relevant to database management and entry-level Data Analyst roles.

## Database Tables

| Table | Description |
|---|---|
| `student` | Stores student names, email addresses, ages, and cities. |
| `course` | Stores course names, fees, and other course details. |
| `enrollment` | Stores student course enrollments, enrollment dates, and status. |

## SQL Concepts Covered

- Database Design: Database and table creation, primary keys, foreign keys, and relationships.
- Constraints:`NOT NULL`, `UNIQUE`, `CHECK`, `DEFAULT`, `ON DELETE CASCADE`, and `ON UPDATE CASCADE`.
- CRUD Operations:`INSERT`, `SELECT`, `UPDATE`, and `DELETE`.
- Joins: `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, and `CROSS JOIN`.
- Aggregate Functions: `COUNT()`, `SUM()`, `AVG()`, `MAX()`, and `MIN()`.
- Grouping and Sorting: `GROUP BY`, `HAVING`, `ORDER BY`, and `DISTINCT`.
- Subqueries: Nested queries, `EXISTS`, and `NOT EXISTS`.
- Set Operations: `UNION` and `UNION ALL`.
- Views and Indexes:Creating, querying, and managing views and indexes.
- Transactions: `START TRANSACTION`, `SAVEPOINT`, `ROLLBACK`, and `COMMIT`.
- Filtering: `WHERE`, `LIKE`, `BETWEEN`, `IN`.

5. Review the query results in the Result Grid.
